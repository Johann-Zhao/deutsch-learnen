# S5 百词斩式单词学习 — 设计规格

> 日期：2026-09-06 · 分支：`phase/s5-baicizhan-learning` · 前序：v4.1.0（S4 已交付 5 词一批 + 三按钮 + 斩）
> 目标：全面参考百词斩的学习逻辑精髓改造单词学习，视觉遵守 `DESIGN.md` zine 纸感规范。

## 已确认的决策（来自头脑风暴）

1. 图片四选一（看词选图）作为核心题型引入，学新词与复习都用。
2. 保留 S4 的「5 词一批」节奏与「认识/不认识/斩」三按钮介绍。
3. 无图词（IMAGE_WORDS 白名单之外的词）遇图片题自动回退文字选择题。
4. 采用方案 A：聚焦学习/复习流程改造，不做词书计划页与词根词缀详情页（无数据支撑）。

## 功能设计

### F1 图片四选一题型（核心）

- 题干：德语词 + 自动播音；4 张图 2×2 网格（移动端 2 列）。
- 正确图：`images/words/<w.id>.jpg`（仅当 `w.id ∈ IMAGE_WORDS`）。
- 干扰图：优先同主题有图词，不足时扩到同级别全部有图词；按中文释义去重，排除答案词。
- 公共构建器：`buildImageChoice(w)` 供学新词加强阶段与复习共用（含选题纯逻辑，可单测）。

### F2 渐进式提示（答错越多提示越强）

- 图片题：错 1 → 显示中文释义提示；错 2 → 排除 2 个错误选项（2 选 1）；错 3 → 高亮正确图，点它收尾。
- 选择题（德↔中、听音）：错 1 → 提示词性 + 首字母遮罩；错 2 → 揭示答案。
- 拼写：错 1 → 首字母遮罩（现状）；错 2 → 揭示一半字母；错 3 → 显示完整答案。
- 每次答错计入 wrongs（影响 FSRS quality 与错题本），但不阻断流程。

### F3 单词详情抽屉

学习介绍、加强、复习的词卡上均可展开详情：词性 + 中文释义、例句 + 翻译、发音按钮；动词额外显示现在时六人称变位小表（复用 `src/conjugate.js` 的 `lookup`）。展开不影响答题判定。

### F4 错词反复出现（session 内再练队列）

- 加强阶段与复习中答错的词进入再练队列，在其后第 3 个位置重新插入（队列不足 3 张则追加到队尾）。
- 同一词当次最多再练 2 轮；仍错则按答错入 FSRS/错题本，明天再见（会话不会死循环）。

### F5 每日词量与进度可见

- 设置页 `dailyNew`（5–30）保留不动。
- 学新词页标题区与今日页任务卡显示「今日新词 x/N」；今日页显示「按当前词量预计 X 天学完本级」。

### F6 复习选词按遗忘曲线优化

- 复习队列由「到期即截取」改为按可提取度升序（`SRS.retrievability` 现有函数）：最容易忘的优先。
- verify（待验证）卡与错题本词汇优先混入队列前部。
- 词汇卡与语法卡仍分开；30 个上限保留。

## 掌握路径定义（「不认识」词学多少轮）

介绍 → 加强三关（图片题 → 选择 → 拼写；答错触发 F2 提示与 F4 再练）→ 本轮连续全对算当次通过 → 按表现定 quality 入 FSRS → 跨天完全由 FSRS 遗忘曲线调度 → 稳定度 ≥21 天判定掌握。「认识」词维持 S4 逻辑（verify → 复习答对转正为斩）。「斩」不变。

## 技术方案

- 改动文件：`src/vocabulary.js`（主要）、`src/views.js`（今日页进度/天数）、`css/style.css`（图片题网格、详情抽屉、提示样式）。
- 不改：srs.js 调度算法、storage、数据结构（sealed/verify 沿用）。
- 复习 `buildQuestion` 题型池：有图词约 40% 概率出图片题，其余题型（gender/trans/listen/cloze/dict）保留。
- 边界：同主题有图词 <4 时跨主题扩充干扰图；图片 `onerror` 时该选项降级隐藏并保证可选出正确答案；`prefers-reduced-motion` 不动效。

## 测试与验收

- `tests/run.js` 新增：干扰图选取（同主题优先、去重、不足扩充）、无图回退、再练队列插入/上限、retrievability 排序的纯逻辑测试。
- E2E（`shots/audit/test_flow.mjs` 扩展）：图片题渲染、选错→提示→重选→选对、详情抽屉展开、再练队列复现。
- `npm test` 全绿 + `npm run build` + `tools/shot.mjs` 双端截图（learn/review 重点）。
- 文档：CHANGELOG [4.2.0]、AGENTS.md 如涉及流程描述同步。

## 明确不做

词书计划页、词根词缀/形近词详情（无数据）、排行榜/游戏化激励、图片题强制覆盖无图词。

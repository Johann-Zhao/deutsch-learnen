## Global Constraints（所有 Task 必须遵守）

1. **测试底线**：`node tests/run.js` 现有 31 项测试必须全程保持绿色；每个 Task 结束跑一遍。
2. **数据格式向后兼容**：`data/vocabulary*.js`、`data/grammar*.js`、`audio/manifest.js`、`images/manifest.js` 的现有全局变量格式不得破坏（`window.VOCAB_THEMES` push 模式、`window.GRAMMAR` push 模式）；只能扩展，不能改结构。
3. **零运行时依赖**：浏览器端不引入任何 npm/CDN 运行时库；esbuild 仅作 devDependency。
4. **file:// 双击可用是硬约束**：S2 打包产物必须是单文件 IIFE bundle（不是 ES module 输出）；数据懒加载用动态 `<script>` 注入（file:// 下可用），不用动态 `import()`。
5. **UI 规范**：遵守 `DESIGN.md` 的色彩/词性三色/动效/文案规范；界面文案保持中文。
6. **提交规范**：`类型(范围): 描述`，类型 ∈ `feat/fix/refactor/test/docs/chore`；每个 Task 一个或多个聚焦提交，禁止夹带无关改动；提交信息用中文。
7. **新逻辑必须可测**：纯逻辑抽成可被 Node 直接测试的模块/函数，测试追加到 `tests/run.js`（不要新建测试文件，沿用现有手写 runner 风格）。
8. **最小改动**：只改本任务需要的代码；不顺手重构无关代码。

## Task 1: 修复答案判定的冠词剥离误判

**分支**：`phase/s1-fixes`（若不存在则从 main 新建）

**问题**：`js/srs.js:104` `stripArticle` 把 `to|zu` 当冠词剥离。德语里 `zu` 是实义成分（如 `zu Hause`、不定式 `zu machen`），用户输入漏掉 `zu` 会被误判为正确。

**要求**：
1. `stripArticle` 只剥离 `der|die|das|ein|eine|einen`，去掉 `to|zu`。
2. 全库 grep 确认 `stripArticle` 的其他调用方（如 vocabulary.js 拼写检验）不受影响或一并修正。
3. `tests/run.js` 追加断言：
   - `DeSRS.matches('Hause', 'zu Hause') === false`（漏 zu 不算对）
   - `DeSRS.matches('Kind', 'das Kind') === true`（名词省略冠词仍算对）
   - `DeSRS.matches('die Kind', 'das Kind') === false`（写错冠词不算对）
   - `DeSRS.matches('nach Hause', 'nach Hause') === true`（回归）
4. 跑 `node tests/run.js` 全绿。

**验收**：`zu Hause` 类答案不再被宽松误判；其余匹配行为不变。

## Task 3: 存储层升级 IndexedDB（公开 API 不变，含迁移与镜像回写）

**分支**：`phase/s1-fixes`

**问题**：localStorage 单点存储，清缓存/换浏览器丢进度，5MB 上限。

**要求**（全部在 `js/storage.js` 内部完成，业务代码零改动或最小改动）：
1. **双后端**：浏览器且 `indexedDB` 可用 → IndexedDB（db 名 `deutsch-lernen`，objectStore `kv`，单条记录 key=`state`）；否则（Node、隐私模式、IDB 打开失败）→ 现有 localStorage/内存路径，行为与今天完全一致。
2. **异步就绪**：新增 `store.ready()` 返回 Promise。浏览器 IDB 路径：打开 db → 读 `state`；若 IDB 为空且 `localStorage['deA1.progress.v1']` 有数据 → 解析迁移进内存 state 并写入 IDB（localStorage 记录保留不删，作为回退）。Node/localStorage 路径下 `ready()` 立即 resolve。`js/app.js` 启动流程改为 `store.ready().then(启动 render)`；迁移期间 UI 可显示简单加载提示。
3. **防抖写入**：`save()` 改为防抖 300ms 批量落盘（state 始终先更新内存）；新增 `store.flush()` 立即写盘，在 `beforeunload`/`visibilitychange:hidden` 时调用。
4. **镜像回写**：IDB 路径下每次落盘同时 best-effort 写 localStorage 镜像（try/catch 吞 QuotaExceeded），作为额外保险。
5. **Node 兼容**：`require('js/storage.js')` 的现有测试全部不受影响；UMD 导出不变。
6. **测试**：`tests/run.js` 追加——注入内存版 fake 异步 KV 后端，验证：迁移逻辑（fake IDB 空 + fake localStorage 有旧数据 → state 正确合并）、防抖合并（连续 3 次 save 只落盘 1 次，可用假定时器或直接调内部函数）、flush 立即落盘。异步后端用注入方式测，不依赖真实 indexedDB。

**验收**：浏览器刷新后进度不丢；从 localStorage 旧版本升级的用户数据自动迁移；`node tests/run.js` 全绿。

**验收**：首屏网络/解析只含当前级别数据；跨级别复习不丢词；`node tests/run.js` 全绿。

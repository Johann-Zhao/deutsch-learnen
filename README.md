# 德语 A1 学习站

面向中文母语学习者的德语 A1 本地学习应用。纯静态网页，无需安装、无需联网（语音朗读使用系统自带语音）。

## 使用方法

用 Chrome 或 Edge 双击打开 `index.html` 即可。

- 词汇：12 个主题、618 个 A1 核心词，例句与朗读
- 复习：间隔重复（SRS）自动安排，答对的词隔得更久再见
- 语法：10 个专题，中文讲解 + 交互练习
- 错题本：词汇和语法错题自动收集，可集中重练
- 进度保存在浏览器 localStorage 中；换电脑前请在「设置 → 导出进度」备份

## 针对的痛点

| 痛点 | 方案 |
|---|---|
| der/die/das 记不住 | 全站词性配色（蓝=der、红=die、绿=das），练习强制选词性 |
| 变位与四格难 | 语法专题交互表格 + 填空练习，错题进入复习队列 |
| 学了就忘 | SM-2 简化版间隔重复，每天自动到期提醒 |
| 不敢开口 | 每个词和例句可朗读（Web Speech API，de-DE） |

## 语音说明

朗读使用系统自带的德语语音。Windows 若无德语语音包，可在
「设置 → 时间和语言 → 语言和区域 → 添加语言 → 德语」中安装，朗读质量会明显提升。

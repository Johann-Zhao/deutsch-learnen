# 德语 A1 学习站

面向中文母语学习者的德语 A1 本地学习应用。纯静态网页，无需安装、无需联网（语音朗读使用系统自带语音）。

## 使用方法

用 Chrome 或 Edge 双击打开 `index.html` 即可。

- 词汇：12 个主题、618 个 A1 核心词，例句与朗读
- 复习：**FSRS 间隔重复**（Anki 同款现代算法）自动安排，答对的词隔得更久再见
- 语法：10 个专题，中文讲解 + 交互练习
- 变位：动词变位查询工具（常用不规则动词内置，规则动词自动推导）
- 错题本：词汇和语法错题自动收集，可集中重练
- 打卡：连胜日历 + 冻结券（漏一天不清零，每满 7 天补 1 张）+ 成就徽章
- 进度保存在浏览器 localStorage 中；换电脑前请在「设置 → 导出进度」备份

## 针对的痛点

| 痛点 | 方案 |
|---|---|
| der/die/das 记不住 | 全站词性配色（蓝=der、红=die、绿=das），练习强制选词性 |
| 变位与四格难 | 语法专题交互表格 + 变位查询工具 + 填空练习 |
| 学了就忘 | FSRS 间隔重复 + 五种复习题型（词性/听音/翻译/例句填空/听写） |
| 不敢开口 | 标准德语音频（见下） |

## 发音说明

全部 618 个单词和 618 个例句已内置**标准德语音频**（微软神经语音 Katja，
由 [edge-tts](https://github.com/rany2/edge-tts) 预先生成，真人级发音），本地离线播放。

- 重新生成（例如换声音）：`pip install edge-tts` 后运行 `python tools/generate_audio.py`
  （可选男声：把脚本里 `VOICE` 改为 `de-DE-ConradNeural`）
- 清单外的文本（如语法例句）会回退到浏览器系统 TTS；Windows 若无德语语音包，
  可在「设置 → 时间和语言 → 语音 → 添加语音 → 德语」安装以改善回退效果。
